Read this first: every owned-hardware result is a floor

The owned-hardware model counts only the accelerator purchase spread over its amortization period and the electricity it draws. It leaves out these items, which can only raise the cost of self-hosting and never raise the cost of an API:

  • host systems
  • networking
  • storage
  • redundancy
  • space
  • cooling capital
  • bandwidth
  • license compliance
  • operating labor
  • safety maintenance

It also does not price capability equivalence: whether the self-hosted model does the same job as the API model you compare it with. Brief 04 does not price this and says it does not believe it can be priced from public information.

Throughput is a figure you supply. A saturated benchmark throughput overstates what a real request pattern achieves, so every result here is also a floor in that sense.

What this is not

  • It is not a recommendation to self-host or to use an API. Brief 04 says no version of this analysis can say which to choose.
  • It is not a forecast. A floor is the lowest cost the model can reach, not the cost you will pay.
  • It would be shown wrong by measured results: a measured power draw below the TDP, a measured throughput for your request pattern, or an invoice that differs from the model.
